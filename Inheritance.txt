It is completely different from method overloadingII. Wherever there is inheritance there is scope for method overridingIII. The overriding method in the child class should contain exactly the same signature as of   parent's    2. Otherwise the method won't be considered as Overridden method3. Only instance methods (Methods without static keyword) can be Overridden. Overriding      will not be applicable for static methods     Annotations in Java---------------------1.
