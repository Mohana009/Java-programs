Database:
---------
Databases are software that stores and manages the permanently in your system

Relational Databases:
MySQL, Oracle, PostgreSQL, MS SQL Server
SQL --> Structured Query Language

Database Languages
------------------
DDL -> Data Definition Language
Helps you work at the table structure level
CARD-T
CREATE, ALTER, RENAME, DROP, TRUNKATE

DML -> Data Manipulation Language
Helps you work at data level
INSERRT, UPDATE, DELETE, SELECT

--To create a table
  DML -> INSERT
  CREATE TABLE table_name(field1 type1, field2 type2, ...)

--To see the description (columns and their types) 
  DESC table_name

--To delete everything from the table
  DELETE FROM table_name;

-- Select command is to fetch the data from table
  SELECT * FROM table_name;

--To remove total table
   DROP TABLE table_name

--To remove specific data from table
  DELETE FROM table_name WHERE condition;
  Without WHERE class
  DELETE FROM table_name -> bad way

--UPDATE is used to modify the data from 1 or more rows
  DML command -> UPDATE
  UPDATE table_name SET col_name = new_value WHERE condition;

ResultSet:
---------
import java.sql.ResultSet;
1. It is uses to store the results of SELECT statement on databases tables
2. ResultSet stores the data retrieved as a result of a SELECT statement
3. Using ResultSet methods, we can access and display the data


st.executeUpdate() and st.executeQuery():
----------------------------------------
Both will take SQL Queries as strings

st.executeUpdate():
It is used to perform
DML (Data Manipulation Language): INSERT, DELETE, UPDATE,	-> Data level
DDL (Data Definition Language): CREATE, ALTER, DROP

Example Queries:
INSERT INTO staff VALUES(101, "Pavan", 80000);
UPDATE staff SET salary = 100000 WHERE id = 101;

st.executeQuery():
Used for SELECT Queries -> Especially designed for SELECT statement
The return type is ResultSet
*For queries which give tables as result
