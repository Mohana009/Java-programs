STRINGS AND ARRAYS IMPORTANT METHODS
-----------------------------------------------------------------------------------------------------------------------
| Method                    | Use                         | Example                             | Result               |
| ------------------------- | --------------------------- | ----------------------------------- | -------------------- |
| `s.length()`              | Length of string            | `s.length()`                        | `5`                  |
| `s.charAt(i)`             | Character at index `i`      | `s.charAt(1)`                       | `'e'`                |
| `s.equals(t)`             | Checks **content equality** | `s.equals("hello")`                 | `true`               |
| `s.equalsIgnoreCase(t)`   | Ignores upper/lower case    | `"Hello".equalsIgnoreCase("hello")` | `true`               |
| `s.compareTo(t)`          | Lexicographical comparison  | `"abc".compareTo("abd")`            | `-1`                 |
| `s.contains("ell")`       | Check substring             | `s.contains("ell")`                 | `true`               |
| `s.indexOf("l")`          | First occurrence index      | `s.indexOf("l")`                    | `2`                  |
| `s.lastIndexOf("l")`      | Last occurrence index       | `s.lastIndexOf("l")`                | `3`                  |
| `s.startsWith("he")`      | Check prefix                | `s.startsWith("he")`                | `true`               |
| `s.endsWith("lo")`        | Check suffix                | `s.endsWith("lo")`                  | `true`               |
| `s.toUpperCase()`         | Converts to upper           | `s.toUpperCase()`                   | `"HELLO"`            |
| `s.toLowerCase()`         | Converts to lower           | `s.toLowerCase()`                   | `"hello"`            |
| `s.trim()`                | Removes spaces (start/end)  | `" hello ".trim()`                  | `"hello"`            |
| `s.replace("l", "r")`     | Replaces characters         | `"hello".replace("l", "r")`         | `"herro"`            |
| `s.substring(start, end)` | Part of string              | `s.substring(1, 4)`                 | `"ell"`              |
| `s.split(" ")`            | Break into array            | `t.split(" ")`                      | `["Hello", "World"]` |

🔹 ARRAYS – Important Methods (from java.util.Arrays)
import java.util.Arrays;
int[] arr = {5, 2, 9, 1};
--------------------------------------------------------------------------------------------------------------------
| Method                                | Use                     | Example                     | Result           |
| ------------------------------------- | ----------------------- | --------------------------- | ---------------- |
| `Arrays.sort(arr)`                    | Sort array              | `Arrays.sort(arr)`          | `[1,2,5,9]`      |
| `Arrays.toString(arr)`                | Print array             | `Arrays.toString(arr)`      | `"[1, 2, 5, 9]"` |
| `Arrays.equals(arr1, arr2)`           | Compare 2 arrays        | `Arrays.equals(arr1, arr2)` | `true/false`     |
| `Arrays.copyOf(arr, n)`               | Copy first `n` elements | `Arrays.copyOf(arr, 2)`     | `[5,2]`          |
| `Arrays.copyOfRange(arr, start, end)` | Range copy              | `copyOfRange(arr,1,3)`      | `[2,9]`          |
| `Arrays.fill(arr, val)`               | Fill all elements       | `fill(arr, 0)`              | `[0,0,0,0]`      |
| `Arrays.binarySearch(arr, val)`       | Search in sorted array  | `binarySearch(arr, 2)`      | `1` (index)      |
--------------------------------------------------------------------------------------------------------------------


🔁 Confusion Clear Cheyyadam:
Concept	              String	             Array
Length	        s.length() (method)	  arr.length (property)
Printing	System.out.println(s)	  Arrays.toString(arr)
Equality	s.equals(t)	          Arrays.equals(arr1, arr2)
Sorting	         Not built-in	          Arrays.sort(arr)
Split/Join	split(" ") returns array  No direct join, use loop/StringBuilder

✅ COMMON INTERVIEW CONFUSION CLARITY
| Concept     | Arrays                                                                     | Strings                                                              |
| ----------- | -------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| `.length`   | Property                                                                   | for arrays                                                           |
| `.length()` | Method                                                                     | for Strings                                                          |
| `.equals()` | Arrays – compare content use `Arrays.equals()` <br> Strings – use directly |                                                                      |
| `.==`       | Reference check (Don't use for content check)                              |                                                                      |
| Sorting     | `Arrays.sort()`                                                            | No direct `sort()` for strings. Convert to char\[] first, then sort. |

✅ Java Arrays – Key Points:
Declaration: int[] arr = new int[5]; or int[] arr = {1,2,3};

Common Methods:

Arrays.sort(arr) – Sort the array.

Arrays.toString(arr) – Print array easily.

Arrays.copyOf(arr, size) – Create a copy.

Arrays.equals(arr1, arr2) – Compare two arrays.

Tricks:

Frequency counts using extra array.

Reverse arrays using swapping logic.

Find duplicates, max/min, sorting.
✅ Java Strings – Key Points:
Declaration: String s = "Hello";

Common Methods:

s.length() – Get string length.

s.charAt(i) – Get char at position i.

s.equals(s2) – Compare two strings.

s.toCharArray() – Convert to array.

s.toLowerCase() / toUpperCase() – Case change.

s.contains("ab"), s.indexOf("a") – Check contents.

s.replace('a', 'b') – Replace characters.

Tricks:

Palindrome check.

Reverse string using loop or StringBuilder.

Anagram checker using sorting.

Frequency using array or map.

🔄 String-Array Conversion:
String s = new String(charArray);

char[] ch = s.toCharArray();

String[] parts = s.split(" ");


💡 ASCII/Unicode:

Characters are stored as numbers.

'A' = 65, 'a' = 97, so 'a' - 'A' = 32.

Used for:

Case conversion.

Frequency array int[26] for lowercase a-z.

Pattern matching.
